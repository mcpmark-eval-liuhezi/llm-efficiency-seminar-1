# llm-efficiency-seminar-1

Tracker and materials for our lab journal club on **efficient LLM training**.

## Structure

- **#1 Efficient LLM Training Literature Review** — parent tracker issue
  - **#2 Survey: Low-Rank Adaptation** — LoRA-style parameter-efficient fine-tuning
  - **#3 Survey: Knowledge Distillation** — distilling knowledge from large models into smaller ones
  - **#4 Survey: Model Quantization** — post-training quantization of LLMs

Each sub-issue carries a shortlist of arXiv papers as a comment.

## Deliverables

- `seminar_reading_notes.docx` — reading notes, one section per sub-issue
- `seminar_summary.pptx` — summary deck, one slide per sub-issue plus a top-pick table
